Quadratic functions – summary

General form: f(x) = ax² + bx + c  (a ≠ 0)

Vertex form: f(x) = a(x − d)² + e, vertex S(d | e)

  • a > 0: parabola opens upward, a < 0: opens downward
  • |a| > 1: stretched, |a| < 1: compressed
  • Roots via the quadratic formula: x = (−b ± √(b² − 4ac)) / 2a
  • Discriminant D = b² − 4ac decides how many real roots

Example: f(x) = 2x² − 4x + 1

⇒ f(x) = 2(x − 1)² − 1, vertex S(1 | −1), D = 8 > 0 ⇒ two real roots
